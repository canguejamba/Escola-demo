## 3.1: Creazione del modulo di contatto e salvataggio messaggi

**As a** user visiting the website,
**I want** to be able to send a message to the project administrators via a contact form,
**So that** I can easily get in touch for inquiries, feedback, or support.

### Acceptance Criteria

1.  A new page must be created at the `/contatti` route.
2.  The page must display a contact form with fields for:
    *   Name (text input, required)
    *   Email (email input, required, validated format)
    *   Subject (text input, optional)
    *   Message (textarea, required)
3.  The form must include client-side validation for required fields and email format.
4.  Upon successful submission, the form data must be sent to a new API endpoint.
5.  The API endpoint must save the message data into the `messages` table in the Supabase PostgreSQL database.
6.  The API endpoint must perform server-side validation of the incoming data.
7.  Upon successful submission, the user should receive a confirmation message on the frontend.
8.  The page layout must be responsive.

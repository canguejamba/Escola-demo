## 5.2: Gestione (CRUD) dei Post del Blog

**As an** administrator,
**I want** to be able to create, read, update, and delete blog posts through a dedicated interface in the admin panel,
**So that** I can manage the content of the blog section efficiently and keep the public portal updated.

### Acceptance Criteria

1.  A new protected page must be created at `/admin/posts` to list all blog posts.
2.  From the `/admin/posts` page, the administrator must be able to:
    *   View a list of all posts with their title, status (published/draft), and publication date.
    *   Navigate to a "Create New Post" page.
    *   Navigate to an "Edit Post" page for an existing post.
    *   Delete an existing post.
3.  A "Create New Post" page (`/admin/posts/create`) must allow the administrator to:
    *   Enter a title, slug, excerpt, full content (using a rich text editor or markdown editor), cover image URL, and set publication status (draft/published).
    *   Save the new post to the database.
4.  An "Edit Post" page (`/admin/posts/[id]/edit`) must allow the administrator to:
    *   Load an existing post's data into the form.
    *   Modify any of the post's fields.
    *   Save the updated post to the database.
5.  All CRUD operations must be performed via secure API endpoints, accessible only to authenticated administrators.
6.  Client-side and server-side validation must be implemented for all form fields.
7.  The admin interface must be responsive.

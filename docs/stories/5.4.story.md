## 5.4: Visualizzazione dei Messaggi di Contatto

**As an** administrator,
**I want** to be able to view all messages received through the contact and volunteer application forms,
**So that** I can respond to inquiries and manage applications efficiently.

### Acceptance Criteria

1.  A new protected page must be created at `/admin/messages` to list all received messages.
2.  The page must display a list of messages, showing at least the sender's name, email, subject (if applicable), type (contact/application), and date received.
3.  The administrator must be able to filter messages by type (e.g., "contact" or "application").
4.  The administrator must be able to mark messages as "read" or "unread".
5.  Clicking on a message in the list should display its full content.
6.  All operations (listing, filtering, marking as read) must be performed via secure API endpoints, accessible only to authenticated administrators.
7.  The admin interface must be responsive.

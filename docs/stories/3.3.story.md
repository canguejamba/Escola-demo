## 3.3: Creazione del modulo per la donazione di beni

**As a** potential supporter,
**I want** to be able to offer material goods (like books, computers, etc.) through a dedicated form,
**So that** I can contribute to the project in a tangible way.

### Acceptance Criteria

1.  The `/partecipa` page must be updated to include a form for donating goods.
2.  The form must include fields for:
    *   Name (text input, required)
    *   Email (email input, required, validated format)
    *   Type of Goods (text input, required)
    *   Description of Goods (textarea, optional)
3.  The form must include client-side validation for required fields.
4.  Upon successful submission, the form data must be sent to a new API endpoint.
5.  The API endpoint must save the donation offer into the `messages` table, with a 'type' field to distinguish it from other messages.
6.  The API endpoint must perform server-side validation of the incoming data.
7.  Upon successful submission, the user should receive a confirmation message on the frontend.
8.  The form and its placement on the page must be responsive.

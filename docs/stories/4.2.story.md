## 4.2: Creazione della pagina di visualizzazione di un singolo post

**As a** user who has clicked on a blog post,
**I want** to see a dedicated page with the full content of that specific post,
**So that** I can read the entire article and get detailed information.

### Acceptance Criteria

1.  A new dynamic page must be created at the `/blog/[slug]` route.
2.  The page must fetch the data for a single blog post based on the `slug` parameter from the URL.
3.  The page must display the post's full title, author (if available), publication date, cover image, and the complete formatted content.
4.  The page must be statically generated with Incremental Static Regeneration (ISR) to ensure it is fast and can be updated periodically.
5.  The page layout must be responsive.
6.  A "Back to blog" link must be present to navigate the user back to the `/blog` page.

## 4.1: Creazione della pagina di elenco dei post del blog

**As a** user visiting the website,
**I want** to see a page that lists all the published blog posts,
**So that** I can stay updated with the latest news and stories from the project.

### Acceptance Criteria

1.  A new page must be created at the `/blog` route.
2.  The page must fetch and display a list of all published blog posts from the database.
3.  Each post in the list must be displayed as a "Post Card" showing at least the post's title, an excerpt, the publication date, and a cover image.
4.  The page should be statically generated with Incremental Static Regeneration (ISR) to ensure it is fast and can be updated periodically without a full rebuild.
5.  The page layout must be responsive.
6.  Clicking on a Post Card must navigate to the detail page for that post (e.g., `/blog/[slug]`).

    *   A `revalidate` time (e.g., 60 seconds) should be set to enable Incremental Static Regeneration (ISR), allowing the page to update with new posts without a new deployment.

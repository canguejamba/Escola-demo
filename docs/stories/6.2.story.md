## 6.2: Integrazione dell'upload di immagini nel form delle comunità

**As an** administrator creating or editing a community entry,
**I want** to be able to upload a representative image directly from the form,
**So that** I can easily manage the visual content for each community.

### Acceptance Criteria

1.  The "Create/Edit Community" form (`CommunityForm.tsx`) must be modified to include a file input field for uploading a representative image.
2.  The user must be able to select an image file (e.g., JPG, PNG) from their local machine.
3.  Upon file selection, the image should be uploaded to a dedicated bucket in Supabase Storage, reusing the API endpoint created in story 6.1.
4.  The API endpoint must ensure the user is an authenticated administrator.
5.  After a successful upload, the API endpoint must return the public URL of the uploaded image.
6.  The frontend form should display a preview of the uploaded image and store the returned URL in its state.
7.  When the community entry is saved (created or updated), this image URL must be saved in the `imageUrl` field of the corresponding community in the database.

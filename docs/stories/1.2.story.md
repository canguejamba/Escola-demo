## 1.2: Implement content and integrate hero image/video for the narrative homepage

**As a** user visiting the website,
**I want** to see engaging content and a visually appealing image/video on the homepage,
**So that** I am immediately drawn into the project's story and encouraged to explore further.

### Acceptance Criteria

1.  The homepage (`pages/index.tsx`) must display a clear, concise narrative message.
2.  An impactful image or video must be integrated into the `Hero` component.
3.  The integrated image/video must be responsive and optimized for web performance.
4.  The image/video should be served from Supabase Storage.
5.  The narrative message and media should effectively convey the project's mission.

### Dev Notes

**CRITICAL:** This section contains extracted information from architecture documents. Do not invent or assume technical details not present here.

*   **Previous Story Insights**: Story 1.1 created the basic structure of the homepage, including the `Hero` component and CTA buttons. This story builds upon that foundation.

*   **Architecture & Tech Stack**:
    *   The frontend is built with **Next.js** and **React**.
    *   The project uses **TypeScript**.
    *   Styling should be done with **TailwindCSS**.
    *   The application is deployed on **Vercel**.
    *   [Source: `docs/architettura/2-ragionamento-architetturale.md`]

*   **File Locations**:
    *   Modifications will primarily be in `pages/index.tsx` and `src/components/Hero.tsx`.
    *   [Source: `docs/architettura/6-vista-logica-componenti-e-relazioni.md` which outlines a standard component-based structure.]

*   **Component Specifications**:
    *   The existing `Hero` component will be updated to include the narrative message and integrate the image/video.
    *   Consider creating a utility for image optimization if not already present.
    *   [Source: `docs/architettura/6-vista-logica-componenti-e-relazioni.md` which describes a component-based frontend architecture.]

*   **Storage**:
    *   Images and static files are stored on **Supabase Storage**.
    *   Ensure proper configuration for accessing media from Supabase buckets.
    *   [Source: `docs/architettura/4-flusso-logico-e-coerenza.md` and `docs/brainstorm-escola-novo-horizonte.md`]

*   **Edge Cases**:
    *   **Image Loading:** If the hero image fails to load, a placeholder background color should be visible, and the `alt` text must be descriptive.
    *   **Video Playback:** If a video is used, ensure fallback for browsers that don't support the format, and consider autoplay/mute settings.

*   **Testing Requirements**:
    *   Unit tests are required for updated components.
    *   **Test Scenarios:**
        *   `Hero`: Verify the narrative message is displayed.
        *   `Hero`: Verify the image/video is rendered and responsive.
        *   `Hero`: Test image loading failure fallback (alt text, placeholder).
        *   `HomePage`: Verify the page renders the updated `Hero` component with content.

### Tasks / Subtasks

1.  **(AC: 1)** Update `pages/index.tsx` to include the narrative message content.
2.  **(AC: 2)** Modify the `Hero` component (`src/components/Hero.tsx`) to accept and display an image or video.
3.  **(AC: 3, 4)** Integrate an impactful image/video from Supabase Storage into the `Hero` component, ensuring it's responsive and optimized.
4.  **(AC: 3)** Implement error handling for image/video loading failures (e.g., display a fallback).
5.  **(AC: 5)** Review the homepage visually to ensure the narrative message and media effectively convey the project's mission.
6.  Update unit tests for the `Hero` component to cover the new content and media integration.
7.  Create or update integration tests to ensure the homepage renders correctly with the new content and media.

## 2.1: Creazione della pagina di elenco delle Comunità

**As a** user visiting the website,
**I want** to see a page that lists all the available communities,
**So that** I can get a quick overview of the different projects and choose one to learn more about.

### Acceptance Criteria

1.  A new page must be created at the `/comunita` route.
2.  The page must display a grid or list of "Community Cards".
3.  Each Community Card must show at least the community's name, a short description, and an image.
4.  The data for the communities can be mocked for this story, but the structure should be based on the `communities` table schema.
5.  The page layout must be responsive.
6.  Clicking on a Community Card should eventually navigate to the detail page for that community (the navigation can be a placeholder for now).

## 1.1: Create the basic structure of the narrative homepage

**As a** user visiting the website for the first time,
**I want** to see a compelling homepage that clearly communicates the project's mission,
**So that** I can quickly understand the purpose of the Escola Comunitária Novo Horizonte and am encouraged to explore further.

### Acceptance Criteria

1.  The homepage must be created as a new page using Next.js.
2.  The page must include a main heading (h1) with the project's name or a compelling tagline.
3.  A section for an impactful image or video must be present.
4.  Two distinct Call to Action (CTA) buttons, "Scopri le comunità" and "Partecipa", must be on the page.
5.  The page layout must be responsive.

### Dev Notes

**CRITICAL:** This section contains extracted information from architecture documents. Do not invent or assume technical details not present here.

- **Previous Story Insights**: No previous stories exist.

- **Architecture & Tech Stack**:

  - The frontend is built with **Next.js** and **React**.
  - The project uses **TypeScript**.
  - Styling should be done with **TailwindCSS**.
  - The application is deployed on **Vercel**.
  - [Source: `docs/architettura/2-ragionamento-architetturale.md`]

- **File Locations**:

  - Create the new homepage at `pages/index.tsx` (assuming a standard Next.js `pages` directory).
  - Create reusable components in a `src/components` directory.
  - [Source: `docs/architettura/6-vista-logica-componenti-e-relazioni.md` which outlines a standard component-based structure.]

- **Component Specifications**:

  - Create a `Header` component.
  - Create a `Footer` component.
  - Create a `Hero` component for the main message and image/video.
  - Create a `CTAButton` component for the call-to-action buttons.
  - [Source: `docs/architettura/6-vista-logica-componenti-e-relazioni.md` which describes a component-based frontend architecture.]

- **Edge Cases**:

  - **Image Loading:** If the hero image fails to load, a placeholder background color should be visible, and the `alt` text must be descriptive.

- **Testing Requirements**:
  - Unit tests are required for new components.
  - **Test Scenarios:**
    - `CTAButton`: Verify the button renders with the correct text label and handles `onClick` events.
    - `Hero`: Verify the `h1` heading is rendered correctly.
    - `HomePage`: Verify the page renders the Hero and two CTA buttons.

### Tasks / Subtasks

1.  **(AC: 1)** Set up the file for the homepage at `pages/index.tsx`.
2.  **(AC: 2)** Create a `Hero` component that contains the main `h1` heading.
3.  **(AC: 3)** Integrate a placeholder for an image within the `Hero` component. Ensure it has a descriptive `alt` tag and a fallback background color in case of loading failure.
4.  **(AC: 4)** Develop a reusable `CTAButton` component.
5.  **(AC: 4)** Add two instances of the `CTAButton` component to the homepage with the labels "Scopri le comunità" and "Partecipa".
6.  **(AC: 5)** Ensure the layout is responsive on mobile, tablet, and desktop screen sizes using TailwindCSS utility classes.
7.  Create unit tests for the `CTAButton`, `Hero`, and `HomePage` components, covering the scenarios listed in the testing requirements.

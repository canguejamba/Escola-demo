## 3.2: Creazione del modulo di candidatura volontari

**As a** potential volunteer visiting the website,
**I want** to be able to submit an application through a dedicated form,
**So that** I can formally express my interest and provide my details to the project administrators.

### Acceptance Criteria

1.  A new page must be created at the `/partecipa` route.
2.  The page must display a volunteer application form with fields for:
    *   Name (text input, required)
    *   Email (email input, required, validated format)
    *   Phone Number (text input, optional)
    *   Area of Interest (e.g., teaching, logistics, fundraising) (select/dropdown, required)
    *   A brief message about their motivation (textarea, required)
3.  The form must include client-side validation for required fields.
4.  Upon successful submission, the form data must be sent to a new API endpoint.
5.  The API endpoint must save the application data into the `messages` table, possibly with a 'type' field to distinguish it from general contact messages.
6.  The API endpoint must perform server-side validation of the incoming data.
7.  Upon successful submission, the user should receive a confirmation message on the frontend.
8.  The page layout must be responsive.

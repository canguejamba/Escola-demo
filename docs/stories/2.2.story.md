## 2.2: Creazione della pagina di dettaglio della Comunità

**As a** user who has clicked on a community card,
**I want** to see a dedicated page with detailed information about that specific community,
**So that** I can fully understand its mission, activities, and needs.

### Acceptance Criteria

1.  A new dynamic page must be created at the `/comunita/[slug]` route.
2.  The page must fetch the data for a single community based on the `slug` parameter from the URL. For this story, the data can be retrieved from the mock data file created in story 2.1.
3.  The page must display the community's name, a full-length description, a gallery of images (can be a simple list of images for now), and any other relevant details (e.g., location, number of students).
4.  The page must be statically generated at build time for performance (using Next.js `getStaticProps` and `getStaticPaths`).
5.  The page layout must be responsive.
6.  A "Back to list" link must be present to navigate the user back to the `/comunita` page.
